# 简报A：高管一页纸（市场扫描）
- 本日入库171条金融机构招投标条目，覆盖银行、信托、农信社、金融租赁等多类主体，软件相关项目占比超85%，核心聚焦信创适配、数据治理、系统运维、监管合规四大方向。头部金融科技厂商在核心系统、数据类项目中优势显著，区域性农信社批量入围项目成为市场重要增量。
- 本日最值得关注的5条：
  1. 安徽省农村信用社联合社数据类/渠道类驻场服务双入围项目（18+19家供应商中标）：覆盖EAST、数据中台、网上银行等数十个模块，是本年度区域性农信体系最大规模科技服务集采项目。
  2. 上海浦东发展银行2026-2029年度金融市场领域信息系统研发专业服务入围（8家头部厂商中标）：锁定未来三年股份行核心赛道合作机会。
  3. 华夏银行财富数字化管理系统项目（恒生电子中标）：聚焦资产配置、收益中心功能，代表股份行财富管理数字化升级主流方向。
  4. 大连银行合规场景大模型应用项目招标：率先布局大模型在银行合规领域落地，为行业提供新赛道参考。
  5. 山东省农村信用社联合社数据分析平台采购（中电金信中标）：发力数据价值挖掘，是农信体系数字化转型典型标杆。
- 类型分布（以库表 sub_type 为准）：中标结果68条，招标公告103条；标题中含流标/终止类约5条，招标类供给仍多于当日中标公示。
