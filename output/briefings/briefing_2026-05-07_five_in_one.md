# 简报A：高管一页纸（市场扫描）
- 本日入库171条金融机构招投标条目，覆盖银行、信托、农信、消金等全品类机构，核心聚焦软件系统建设、运维服务、信创改造三大方向，头部厂商在数据库、财富管理系统等赛道优势凸显，区域性农信社批量采购成为核心亮点。
- 类型分布（库表 sub_type 核对）：中标结果68条，招标公告103条；标题中含流标/终止等其它情形若干条（模型分项仅供参考，以库为准）。
- 本日最值得关注的5条：
  1. 安徽省农信社数据类/渠道类开发及运维人员驻场服务双入围项目，18家金融科技厂商中标，覆盖数据中台、柜面系统等数十个场景，是本年度农信体系最大规模外包项目之一。
  2. 浦发银行2026-2029年度金融市场领域信息系统研发专业服务入围项目，8家头部厂商中标，锁定未来三年核心业务赛道合作权。
  3. 华夏银行财富数字化管理系统由恒生电子中标，凸显头部厂商在财富管理数字化领域的技术垄断性。
  4. 上海农商银行信创服务器购置招标明确指定鲲鹏、海光服务器，标志着城商行信创硬件采购进入规模化落地阶段。
  5. 大连银行合规场景大模型应用项目启动招标，是大模型技术在金融合规领域的典型落地需求。

# 简报C：竞争格局快照（厂商与价格战）
- **头部厂商中标情况**：恒生电子成为最大赢家，先后中标外贸信托估值系统/分布式数据库、华夏银行财富数字化管理系统、哈尔滨银行交易银行数智化平台、浦发银行金融市场系统研发入围项目，累计中标5个核心项目；神州数码融信、深圳市长亮科技各中标3个项目，覆盖农信入围、银行核心系统等赛道；中电金信中标2个农信及银行数据平台项目。
- **价格相关信息**：本次入库条目多数未披露项目预算、人力单价（万元/人月）等价格字段，无法归纳价格战相关情况。

# 简报D：区域与机构类型
- **机构类型分布**：银行类项目占比最高，约120条（涵盖国有大行、股份制银行、城商行、农商行）；农信/农商联合社类约25条；信托类约10条；消金类1条；金融租赁类2条；人行、资管公司等其它类约13条。
- **区域性机会提示**：
  1. 安徽省农信社批量入围项目释放海量数据、渠道类运维需求，可跟进中标厂商的分包或二期合作机会；
  2. 广东、广西、云南等南方省份农信/城商行的网络安全、信创改造项目密集招标，区域需求旺盛；
  3. 东北区域（黑龙江、辽宁）的硬件采购、机房改造项目集中，如黑龙江金控AI算力设备采购、盛京银行网络安全维保项目。
